# Support

## Getting Help

- **GitHub Issues**: Bug reports and feature requests
- **GitHub Discussions**: Questions, ideas, and community help

## Before Opening an Issue

1. Check existing issues for duplicates
2. Include your platform and version
3. For bugs, include steps to reproduce
4. For audio issues, include device information
5. Export and attach diagnostics (Settings > Debug > Export Diagnostics)

## Diagnostics

PRX Voice Client can export a diagnostics bundle containing:
- Application version and OS info
- Session state and metrics
- Recent event log (sanitized)
- Configuration snapshot (sanitized)

No raw audio data is included in diagnostics exports.
