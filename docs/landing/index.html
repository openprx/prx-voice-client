Capabilities

Built for real-time voice, not chat bubbles

🎙

Always Listening

Desktop stays resident. One hotkey and you're talking. No app switching, no friction, no waiting.

✋

Natural Interruption

Cut in mid-sentence. The AI stops immediately. You take over. Just like a real conversation.

🔄

Multi-turn Context

Follow up, correct, refine. The session holds context across turns without starting over.

🔊

Audio Pipeline

VAD, echo control, jitter buffer, device routing. Industrial-grade audio engineered in Rust.

🌐

i18n Ready

English and Chinese built-in. Add any language with a translation map. UI switches in real time.

🛡

Privacy First

Audio captured only when active. Logs sanitized by default. No telemetry without consent.

Material 3. Foreground service. Audio focus. Quick voice sessions anywhere.

Up and running in seconds

terminal
# Clone and build
git clone https://github.com/openprx/prx-voice-client.git
cd prx-voice-client
cargo run -p prxvc-desktop

# Or build a release binary
cargo build -p prxvc-desktop --release

# Run all 151 tests
cargo test --workspace
